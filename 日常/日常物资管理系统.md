## [ims]

1. 适合已经有数据库的直接填写启动（端口9292）
```bash
git clone https://github.com/juhedata/ims.git && cd ims && cp .env.example .env && sed -i 's/\r$//' backend/scripts/docker-entrypoint.sh && chmod +x backend/scripts/docker-entrypoint.sh && sed -i 's/^FRONTEND_PORT=.*/FRONTEND_PORT=9292/' .env && sed -i 's|^CORS_ORIGINS=.*|CORS_ORIGINS=http://localhost:9292,http://127.0.0.1:9292|' .env && printf '%s\n' 'services:' '  backend:' '    extra_hosts:' '      - "host.docker.internal:host-gateway"' '    environment:' '      MYSQL_HOST: host.docker.internal' '      MYSQL_PORT: "3306"' '      MYSQL_USER: root' '      MYSQL_PASSWORD: "779604436aA"' '      MYSQL_DB: ims' > docker-compose.override.yml && docker run --rm --add-host=host.docker.internal:host-gateway mysql:5.7 mysql -hhost.docker.internal -uroot -p'779604436aA' -e "CREATE DATABASE IF NOT EXISTS ims DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;" && docker compose up -d --build --no-deps backend frontend
```

2. 适合啥都没有的直接启动（端口9292）：
```bash
git clone https://github.com/juhedata/ims.git && cd ims && cp .env.example .env && sed -i 's/\r$//' backend/scripts/docker-entrypoint.sh && chmod +x backend/scripts/docker-entrypoint.sh && sed -i 's/^FRONTEND_PORT=.*/FRONTEND_PORT=9292/' .env && sed -i 's|^CORS_ORIGINS=.*|CORS_ORIGINS=http://localhost:9292,http://127.0.0.1:9292|' .env && docker compose up -d --build
```
