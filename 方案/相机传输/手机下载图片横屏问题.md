# 手机下载图片横屏问题

Sony 相机经 FTP 上传的 JPG，常带有 EXIF `Orientation`（如 `Rotate 270 CW`）。部分手机浏览器下载时不按该标记旋转，导致横拍照片显示方向错误。

## 方案概览

在 FTP 上传目录用 `exiftran` 原地无损纠正方向，再交给 Nextcloud 读取：

1. `/home/apple/ftp` 作为 Sony FTP 上传根目录（可上传到任意子目录，如 `ftp/嘟嘟`、`ftp/lz`）
2. `inotifywait -r` 递归监听整个 FTP 树（含新建子目录）
3. 文件落到哪个目录，就只处理**该目录**下的 JPG（不递归更深子目录）
4. 自动等待 JPG 上传完成
5. `exiftran -ai` 原地无损纠正方向（`Orientation` 变为正常）
6. Nextcloud 直接读取处理后的文件
7. 手机浏览器下载即为正确方向

> `exiftran -a` 根据 EXIF Orientation 自动旋转，`-i` 为原地修改；处理后默认将 Orientation 设为 1，并同步处理 EXIF 缩略图。做的是 JPEG 无损变换，不是重新编码。

服务器：`apple@10.147.47.20`

## 2. 处理脚本

```bash
sudo nano /usr/local/bin/sony-photo-auto-orient.sh
sudo chmod +x /usr/local/bin/sony-photo-auto-orient.sh
```

```bash
#!/bin/bash
BASE_DIR="/home/apple/ftp"
LOG_FILE="/var/log/sony-photo-auto-orient.log"
TARGET="${1:-$BASE_DIR}"

# 若传入的是文件路径，取其所在目录
if [ -f "$TARGET" ]; then
    TARGET="$(dirname "$TARGET")"
fi

# 只允许处理 FTP 根目录及其子目录
case "$TARGET" in
    "$BASE_DIR"|"$BASE_DIR"/*) ;;
    *)
        echo "[$(date '+%Y-%m-%d %H:%M:%S')] Invalid target: $TARGET" >> "$LOG_FILE"
        exit 1
        ;;
esac

if [ ! -d "$TARGET" ]; then
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] Target not found: $TARGET" >> "$LOG_FILE"
    exit 0
fi

# 等待文件大小稳定
wait_file_stable() {
    local FILE="$1"
    local LAST_SIZE=-1
    local SIZE=0
    local STABLE_COUNT=0

    while true; do
        if [ ! -f "$FILE" ]; then
            return 1
        fi

        SIZE=$(stat -c%s "$FILE" 2>/dev/null)

        if [ "$SIZE" -eq "$LAST_SIZE" ]; then
            STABLE_COUNT=$((STABLE_COUNT + 1))
        else
            STABLE_COUNT=0
        fi

        # 连续 3 次大小不变化，每次间隔 2 秒
        # 即至少 6 秒没有继续写入
        if [ "$STABLE_COUNT" -ge 3 ]; then
            return 0
        fi

        LAST_SIZE="$SIZE"
        sleep 2
    done
}

echo "[$(date '+%Y-%m-%d %H:%M:%S')] Scan started in: $TARGET" >> "$LOG_FILE"

# 只处理触发目录下的 JPG/JPEG（不递归子目录）
find "$TARGET" -maxdepth 1 -type f \
    \( -iname "*.jpg" -o -iname "*.jpeg" \) \
    -print0 |
while IFS= read -r -d '' FILE; do

    echo "[$(date '+%Y-%m-%d %H:%M:%S')] Checking: $FILE" >> "$LOG_FILE"

    # 等待文件上传完成
    if ! wait_file_stable "$FILE"; then
        echo "[$(date '+%Y-%m-%d %H:%M:%S')] File disappeared: $FILE" >> "$LOG_FILE"
        continue
    fi

    # exiftran 自动根据 Orientation 旋转
    # -a = automatic，根据 EXIF Orientation
    # -i = inplace，原地修改
    if /usr/bin/exiftran -ai "$FILE" >> "$LOG_FILE" 2>&1; then
        echo "[$(date '+%Y-%m-%d %H:%M:%S')] Processed: $FILE" >> "$LOG_FILE"
    else
        echo "[$(date '+%Y-%m-%d %H:%M:%S')] ERROR: $FILE" >> "$LOG_FILE"
    fi

done

echo "[$(date '+%Y-%m-%d %H:%M:%S')] Scan finished in: $TARGET" >> "$LOG_FILE"
```

## 3. 递归监听脚本

```bash
sudo nano /usr/local/bin/sony-photo-auto-orient-watch.sh
sudo chmod +x /usr/local/bin/sony-photo-auto-orient-watch.sh
```

```bash
#!/bin/bash
# 递归监听 /home/apple/ftp，文件落到哪个目录就处理哪个目录
BASE_DIR="/home/apple/ftp"
LOG_FILE="/var/log/sony-photo-auto-orient.log"
PENDING_DIR="${RUNTIME_DIRECTORY:-/run/sony-photo-auto-orient}"
DEBOUNCE_SEC=6

mkdir -p "$PENDING_DIR"

echo "[$(date '+%Y-%m-%d %H:%M:%S')] Watcher started on $BASE_DIR" >> "$LOG_FILE"

# 后台：定期处理待处理目录（同一目录多次上传会合并）
(
  while true; do
    sleep "$DEBOUNCE_SEC"
    shopt -s nullglob
    for marker in "$PENDING_DIR"/*.dir; do
      [ -f "$marker" ] || continue
      dir=$(cat "$marker" 2>/dev/null) || continue
      rm -f "$marker"
      /usr/local/bin/sony-photo-auto-orient.sh "$dir"
    done
  done
) &
WORKER_PID=$!

cleanup() {
  kill "$WORKER_PID" 2>/dev/null || true
  wait "$WORKER_PID" 2>/dev/null || true
  echo "[$(date '+%Y-%m-%d %H:%M:%S')] Watcher stopped" >> "$LOG_FILE"
}
trap cleanup EXIT INT TERM

# -m 持续监听，-r 递归（含新建子目录）
inotifywait -m -r -e close_write,moved_to --format '%w%f' "$BASE_DIR" |
while IFS= read -r FILE; do
  lower=$(printf '%s' "$FILE" | tr 'A-Z' 'a-z')
  case "$lower" in
    *.jpg|*.jpeg)
      DIR=$(dirname "$FILE")
      HASH=$(printf '%s' "$DIR" | md5sum | awk '{print $1}')
      printf '%s\n' "$DIR" > "$PENDING_DIR/$HASH.dir"
      ;;
  esac
done
```

## 4. systemd service

```bash
sudo nano /etc/systemd/system/sony-photo-auto-orient.service
```

```ini
[Unit]
Description=Auto orient Sony FTP photos (recursive watch)
After=local-fs.target

[Service]
Type=simple
ExecStart=/usr/local/bin/sony-photo-auto-orient-watch.sh
Restart=always
RestartSec=3
RuntimeDirectory=sony-photo-auto-orient

[Install]
WantedBy=multi-user.target
```

```text
Processed: /home/apple/ftp/lz/DSC00001.JPG
Scan finished in: /home/apple/ftp/lz
```

### 自动触发

相机 FTP 上传 JPG 到任意子目录（如 `/home/apple/ftp/甘坑`），约数秒后日志应出现对应目录的 `Scan started in` / `Processed`。

> 注意：部分旧目录（如 `嘟嘟`）属主可能是 `www-data`。本机 `apple` 用户可能写不进去，但相机 FTP 上传一般可以。自动处理不依赖本地写权限，只要文件进目录就会处理。

## 说明

| 项                   | 说明                                                                   |
| -------------------- | ---------------------------------------------------------------------- |
| 监听范围             | `/home/apple/ftp` 整棵目录树，含新建子目录                             |
| 处理粒度             | 只处理「触发文件所在目录」一层 JPG，不递归                             |
| 同一目录已有大量照片 | 有新文件触发时，会扫描该目录全部 JPG（已是 normal 的再跑一次通常很快） |
| 旧版 systemd.path    | 已弃用（`PathChangedGlob` 在当前 systemd 无效，无法监听子目录）        |
