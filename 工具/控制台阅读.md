npm install -g readshell

novel import ~/books/      # 递归扫描目录
novel list                 # 查看书库
novel resume               # 从上次位置继续
novel login                # 浏览器授权，30秒完成
novel sync                 # 手动同步进度和书签
                           # 退出阅读时也会自动同步



按键	操作
j / ↓	向下滚动
k / ↑	向上滚动
Space	翻页（下一页）
b / Esc	老板键（切换伪装画面）
m	添加书签
g	跳转到开头
G	跳转到结尾
/	搜索
q	退出
?	显示帮助
